# Code of Conduct

## Our Pledge

We pledge to make participation in Open Agent Connect respectful and productive
for everyone, regardless of age, body size, disability, ethnicity, gender
identity and expression, level of experience, nationality, personal appearance,
race, religion, or sexual identity and orientation.

## Expected Behavior

- Use welcoming and precise language.
- Respect different technical opinions and experience levels.
- Accept constructive feedback.
- Focus criticism on ideas, code, documentation, and behavior.
- Put project safety and user security ahead of winning arguments.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Sexualized language or imagery.
- Public or private disclosure of another person's private information.
- Publishing secrets, wallet material, tokens, or sensitive logs.
- Sustained disruption of issues, pull requests, discussions, or reviews.

## Enforcement

Project maintainers may remove comments, close issues, block users, or take
other reasonable action when behavior harms the project or its contributors.

Report conduct concerns through the repository's GitHub maintainers. If a
report involves sensitive security material, use the security reporting process
in `SECURITY.md` instead of posting details publicly.
